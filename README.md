## 🚀 Sobre este perfil

Esta conta foi criada para reunir os **projetos desenvolvidos em aulas de tutoria da [Kodland](https://kodland.org/)**, no curso de **Python Pro**.

Cada repositório aqui nasceu de uma aula: são projetos pensados para ensinar na prática, passo a passo, como construir aplicações web de verdade — do primeiro formulário até um sistema com cadastro e login de usuários.
